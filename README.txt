WORLD TOUR EXPLORER
===================

FILES
- index.html : Main website page
- style.css  : Responsive design and styling
- script.js  : Language toggle, destination search and budget estimator

HOW TO OPEN
1. Extract the ZIP file.
2. Open the world_tour_explorer folder.
3. Tap/click index.html to preview in a browser.

IMPORTANT
- Internet is required for Google Fonts and the Unsplash photos.
- Budget values are sample estimates in INR, not live quotes.
- Country links currently jump to the trip planner; individual country detail pages can be added in the next development stage.
- Replace the sample contact email before publishing.
